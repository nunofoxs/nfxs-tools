# NFXS Tools

**Free tools to diagnose, maintain, and support FiveM and RedM players.**

The 7 apps you need for a smoother roleplay. Each one does exactly one job, no bloat, no hidden behavior — every script is plain text you can open and read before you run it.

## What's inside

| App | What it does |
|---|---|
| 🧭 [NFXS Hub](nfxs-apps/Hub) | Opens every NFXS app you have installed, from one place |
| 🔧 [NFXS GameCheck](nfxs-apps/NFXS%20GameCheck) | Checks whether your FiveM/RedM installation is ready to play |
| 🖥️ [NFXS Performance](nfxs-apps/NFXS%20Performance) | Checks if your CPU, GPU, RAM and disk space meet FiveM/RedM's requirements |
| 🌐 [NFXS Connection](nfxs-apps/NFXS%20Connection) | Tests your internet, DNS and the server itself to find out where a connection problem really is |
| 🧹 [NFXS Cleaner](nfxs-apps/NFXS%20Cleaner) | Clears your FiveM/RedM cache in one click when the game starts acting up |
| 💥 [NFXS CrashCheck](nfxs-apps/NFXS%20CrashCheck) | Finds your crash reports automatically and explains what's in them, ready to share with server staff |
| 🎬 [NFXS Clips](nfxs-apps/NFXS%20Clips) | Finds the screenshots and clips Windows already saved from your FiveM/RedM sessions |

## How to install

1. Download and extract this folder anywhere on your PC.
2. Double-click **`Start NFXS Hub.bat`**.
3. Click any app's tile to open it.

That's it — no installer, no admin rights, nothing else to configure. Windows may show a "Windows protected your PC" warning the first time you run any of these (normal for any app that isn't from a paid "recognized publisher" — click "More info" → "Run anyway").

## Just want one app?

Copy `Start NFXS Hub.bat`, the `nfxs-apps/NFXS.ico` file, the whole `nfxs-apps/Hub/` folder, and that one app's own folder under `nfxs-apps/`. NFXS Hub only shows tiles for the apps actually present.
