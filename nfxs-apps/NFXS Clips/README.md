# 🎬 NFXS Clips

**Finds the screenshots and clips Windows already saved from your FiveM/RedM sessions.**

## What it does

NFXS Clips gathers the FiveM/RedM screenshots and clips Windows already saved for you, thumbnails included, so you never have to dig through a folder. It never records anything itself — that's Windows' own job (Win+Alt+G / Win+Alt+R / Win+Alt+PrtScn).

## Key features

- Shows your 5 most recent FiveM/RedM screenshots and clips, with a real thumbnail
- One click to open the full captures folder
- One click to open the Windows Game Bar overlay (Win+G)
- Shows whether Windows' own recording (Game DVR) is enabled
- Disk space used by your captures

## Details

| | |
|---|---|
| **Category** | Organization |
| **Changes your PC** | No — never touches your original capture files |
| **Compatibility** | Windows 10/11 (64-bit) — needs Xbox Game Bar enabled |

## When to use it

After recording something, or to organize older clips.

## How to run it

Open it through **NFXS Hub**, or double-click `NFXS Clips.bat` directly.
