NFXS | GAME CHECK
=================

COMMENT L'OUVRIR
-----------------
Ouvrez "NFXS Hub" et cliquez sur la vignette "NFXS GameCheck".

La première fois, Windows peut afficher "Windows a protégé votre PC".
Cliquez sur "Plus d'infos" puis sur "Exécuter quand même".


ÉTAPE PAR ÉTAPE
----------------
1. Choisissez le jeu : FiveM ou RedM.
2. L'outil affiche immédiatement le diagnostic complet : installation,
   GTA V/RDR2, mods graphiques, compatibilité, composants requis, cache,
   espace disque, et si le jeu est ouvert.
3. Vous voyez "Cache élevé" ou similaire ? Cliquez sur le lien pour
   ouvrir NFXS Cleaner directement.
4. Vous avez résolu quelque chose ? Cliquez sur "Vérifier à nouveau".
