# 🔧 NFXS GameCheck

**Checks your FiveM or RedM install is actually ready to play — before you press play.**

## What it does

NFXS GameCheck looks at your FiveM/RedM install before you do — base game, system compatibility, graphics mods, cache level, free disk space — and tells you plainly what's fine and what needs attention. Read-only: it never changes or deletes anything.

## Key features

- Install detection + path
- Base game detection (GTA V / RDR2)
- Graphics mod detection (informational only, never judged)
- Windows 10+/64-bit compatibility + Visual C++ Redistributable check
- Cache level readout, with a direct link to NFXS Cleaner if it's already installed
- Free disk space and an overall result summary

## Details

## When to use it

Before you play, or whenever something about your install/mods feels off.

## How to run it

Open it through **NFXS Hub**, or double-click `NFXS GameCheck.bat` directly.
