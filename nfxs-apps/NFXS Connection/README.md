# 🌐 NFXS Connection

**Finds out whether the problem is your internet, or the server — before you blame either.**

## What it does

NFXS Connection tests your internet, DNS, and the specific FiveM/RedM server you're trying to reach, then explains what's actually going on in plain language. It never scans ports, never lists players, and never puts extra load on any server.

## Key features

- Internet and DNS check
- FiveM/RedM server endpoint check (server name shown only as identity confirmation)
- ICMP ping (min/avg/max/jitter/loss), always shown as informational, never conclusive on its own
- A diagnosis engine that correlates everything into a plain-language explanation

## Details

| | |
|---|---|
| **Category** | Diagnostics |
| **Changes your PC** | No |
| **Compatibility** | Windows 10/11 (64-bit) |

## What it never does

No port scanning, no player lists, no server resource enumeration. This is a hard boundary, not a style choice — Connection diagnoses your own connection, never the server's infrastructure.

## When to use it

Before you play, or whenever you suspect a connection problem.

## How to run it

Open it through **NFXS Hub**, or double-click `NFXS Connection.bat` directly.
