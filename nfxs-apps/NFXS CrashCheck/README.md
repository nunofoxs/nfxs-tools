# 💥 NFXS CrashCheck

**Turns a game crash into a report you can actually hand to server staff.**

## What it does

NFXS CrashCheck finds your FiveM/RedM crash reports automatically and explains what's in them — confirmed facts vs. possible causes, client-side vs. server-side — then hands you a ready-to-paste report for server staff.

## Key features

- Automatically finds crash reports, most recent first
- Plain-language categorization (type of problem + client-side/server-side, when the evidence supports it)
- Detailed evidence list for anyone who wants the technical detail
- "Copy report" button, ready to paste into Discord or a support ticket
- "Export files (.zip)" bundles the dump, log, and report together on your Desktop

## Details

| | |
|---|---|
| **Category** | Diagnostics |
| **Changes your PC** | No — never modifies or deletes the original crash files |
| **Compatibility** | Windows 10+ 64-bit |

## When to use it

Right after a crash.

## How to run it

Open it through **NFXS Hub**, or double-click `NFXS CrashCheck.bat` directly.
