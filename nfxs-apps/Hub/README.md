# 🧭 NFXS Hub

**The single click that opens every other NFXS app you have installed.**

## What it does

NFXS Hub is the home screen for every NFXS tool you have installed. It scans your NFXS Tools folder, shows a tile for each app, and launches or closes them with one click — no shortcuts to hunt for, no folders to remember.

## Key features

- Auto-discovers every NFXS app installed in the same folder (no fixed list)
- Launch or close any app with one click; tile color reflects whether it's running
- Shared language and accent color across every NFXS app

## When to use it

Always — it's the recommended starting point for every other NFXS app.

## How to run it

Double-click `NFXS Hub.bat`. No installation needed, no admin rights required.
