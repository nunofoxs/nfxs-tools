# 🖥️ NFXS Performance

**Tells you whether your PC actually meets FiveM/RedM's real requirements — not a guess.**

## What it does

NFXS Performance checks your CPU, GPU, RAM and free disk space against FiveM/RedM's real Steam requirements and gives each one a clear pass or fail. One snapshot, no live monitoring, no changes made to your system.

## Key features

- System check (Windows 10+/64-bit)
- RAM pass/fail against the official requirement
- GPU VRAM pass/fail (correctly picks the right adapter on hybrid integrated+dedicated systems)
- Free disk space check on the drive the game is actually installed on
- CPU shown informationally (no verdict — core count alone isn't a fair comparison across generations)

Before installing/playing, or whenever performance feels off.
