# 🧹 NFXS Cleaner

**Clears FiveM/RedM cache in a couple of clicks when the game starts acting up.**

## What it does

NFXS Cleaner clears your FiveM/RedM cache in one click — quick or full — and can reopen the game for you right after. Built for the moment right after a graphics mod messes something up.

## Key features

- Quick (recommended) or Full clean mode
- Cache level readout with a verdict (normal / attention / critical)
- Optional server address to reopen the game directly into it
- Reopens the game automatically after cleaning, if you want

## Details

| | |
|---|---|
| **Category** | Cleaning |
| **Changes your PC** | Yes — deletes cache files, only when you click Clean |
| **Compatibility** | Windows 10/11 (64-bit) |

## When to use it

When the game misbehaves after installing graphics mods, or as periodic maintenance.

## How to run it

Open it through **NFXS Hub**, or double-click `NFXS Cleaner.bat` directly.
